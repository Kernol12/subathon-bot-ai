   `$id` and both anchors preserve the selected lexical resource scope, including
   the resolver returned from the child JSON Pointer. No arbitrary raw-pointer
   conversion helper is substituted for those SDK calls.

   registers root and their exact relative IDs. Literal const/enum/default/examples

   comparisons deliberately avoid inventing keyword-set iteration order.

   `$defs`. Both real validator classes accept the literal integer with zero
