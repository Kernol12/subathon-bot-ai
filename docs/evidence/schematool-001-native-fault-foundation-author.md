absent or that a clean boolean substitutes for actual kernel state.
The [mincore contract](https://man7.org/linux/man-pages/man2/mincore.2.html)

supports the controlled soft-limit/EMFILE/restoration test. This is one tiny
per-process admission failure, not a claim of host exhaustion or production
