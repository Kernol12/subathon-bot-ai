# TESTCLEAN-006 — Replace giant unreproducible fixtures

Module: Test infrastructure. Kind: cleanup. Specification: v0.45; §17.
Contract revision: current fixture/oracle contracts for the affected suites.
Parent: EPIC-028. Depends on: TESTCLEAN-005. Shared-file ownership: large JSON fixtures
and their owning Qt tests, including application service, bundle, holds, reference capture
and original claims.

## Scope

For fixtures exceeding roughly 500 lines, either commit and review a deterministic
generator under `tools/` or replace repeated dumps with small, named, hand-derived
scenarios. Prioritize fixtures whose generator is missing and whose rows are addressed
by opaque integer indices. Keep a compact scenario for each distinct behavior.

## Acceptance criteria

- Every expected value remains independently derived and is not generated by the system
  under test; record generator inputs/outputs if a generator is retained.
- Scenarios have meaningful names and failure messages, and cover the behaviors that
  justified the original fixture without bulk duplicate schema dumps.
- No assertion or behavior is removed solely to meet a line-count target; record exact
  retained/replaced coverage in the PR.
- Focused suites pass and a separate reviewer approves the oracle provenance, scenario
  coverage and any baseline change.
