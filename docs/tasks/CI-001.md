## Recovery contract revision 1

The standard-library Python helper is invoked immediately after checkout and before
any package operation in all nine Ubuntu24.04 APT lanes (SQL fixture reproduction
may remain before it). It refuses use outside GitHub Actions on Ubuntu24.04 before
any commands or writes. It checks the existing ubuntu.sources uses GitHub's known
mirror+file:/etc/apt/apt-mirrors.txt source; unexpected layouts fail before writes.

Record resolver configuration/status and address lookups for azure.archive.ubuntu.com,
archive.ubuntu.com and security.ubuntu.com, with at most10 seconds per diagnostic
command. These diagnostics are best effort and clearly reported; they never count
as dependency admission or acceptance. No DNS-server configuration is changed.

Through checked sudo tee, replace only /etc/apt/apt-mirrors.txt with these literals:

```text
https://archive.ubuntu.com/ubuntu/
https://security.ubuntu.com/ubuntu/
```

Write /etc/apt/apt.conf.d/99-subathon-network with Acquire::Retries "1";
Acquire::http::Timeout "15"; Acquire::https::Timeout "15"; and
APT::Update::Error-Mode "any";. All existing trust/keyring/component/suite/architecture
settings stay intact. No proxies, hardcoded mirror addresses, third-party resolvers
or authentication bypass. Run checked sudo apt-get update with a300-second process
deadline; configuration writes use10-second deadlines. Report critical command
failure/timeout as nonzero. Existing job timeouts remain the overall bound.
Remove redundant old apt-get update calls; keep all existing install/download
commands, exact package versions, hashes and ordinary test commands unchanged.

## Independent examples and acceptance

- GitHub Ubuntu24.04 with the admitted source layout: diagnostics, exact two mirror
  lines and literal network config precede a checked update; success only after update.
- Azure lookup fails while primary/security work: diagnostics record that failure,
  official mirrors are configured and the actual update decides success.
- Local invocation or another distro/version: explicit refusal before any command/write.
- Unknown APT source layout: explicit refusal before any configuration write.
- A configuration write fails: propagate the failure and do not start update.
- Update fails or times out: command stays failed; no fabricated success or stale-index
  success. Package acquisition and all nine selected-host bodies must actually pass.
