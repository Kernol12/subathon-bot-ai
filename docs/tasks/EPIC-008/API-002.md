## Acceptance criteria

- Validate versioned requests with operation IDs and expected revisions before dispatching commands.
- Reject stale/unauthorized calls at execution; encode 64-bit/accounting values as strings and rationals as numerator/denominator strings.

## Boundary and failure cases

Cover malformed/oversized exact values, duplicate operations, revoked permissions and stale preview conflicts without leaking private fields.
