## Acceptance criteria

- Marshal requests onto the authoritative Qt queue and return correlated results without blocking the writer on network callbacks.
- Define cancellation/backpressure/shutdown behavior and dispose framework/SQL owners on their correct threads.
- Prove positive ordinary activation on the actual current catalog/installation path in Q and N, plus fresh/old/future-schema and malformed/uncertain-source refusal without auto migration or setup.
- Track actual repository mutations through host-controlled finalization and prove epoch E→F automatically rebinds generation7→8, rejecting old queued work/publication without exposing commit-capable tickets.
- Link shipped production Drogon/signal/elapsed adapters in N; prove early signals, shared host/native elapsed wiring and actual callback/writer/join barriers. Synthetic clock probes remain acceptance-only and never establish trusted UTC.
