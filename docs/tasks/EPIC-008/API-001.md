## Acceptance criteria

- Marshal requests onto the authoritative Qt queue and return correlated results without blocking the writer on network callbacks.
- Define cancellation/backpressure/shutdown behavior and dispose framework/SQL owners on their correct threads.

## Boundary and failure cases

Test request during shutdown, timeout, repeated startup failure and queued-work drain with Qt Test/fake transport.

Use all HL01–17 and the additional resource/source/thread/barrier families in the
consumer proposal. Keep Qt/fake service and actual corrected-framework Linux
child/peer checks; a simulated ready host, diagnostic listener or DTO cannot close
normal-startup/current-source acceptance. One start/framework lifetime per process;
bind/listen failure is process-terminal and retries use fresh children.
