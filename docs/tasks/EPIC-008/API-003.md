## Acceptance criteria

## SPIKE-001 persistent-connection finding

The [pinned-framework experiment](../../evidence/spike-001-bridge-validation.md)
found that its received WebSocket Close path half-closes TCP before the controller
callback. The one-command probe initiates a normal server close after its reply;
that does not validate persistent production WebSockets. APITEST-003 must test
multiple messages and state updates per connection, client/server-initiated close
frames, disconnect/reconnect and shutdown with pending updates on an actual selected
framework version. Resolve the observed close behavior through a reviewed framework
version/patch or compatible adapter before claiming support; do not adopt the
probe's per-command close as the management/viewer product behavior.
