# v0.45 requirements and integration evidence matrix

Draft for [VALIDATE-001 #535](https://github.com/Kernol12/subathon-bot-ai/issues/535). Repository snapshot `b1c02b0d83e552e782b63189228a290a7524a2e3`. Requirements come from [docs/specification.md](https://github.com/Kernol12/subathon-bot-ai/blob/b1c02b0d83e552e782b63189228a290a7524a2e3/docs/specification.md). Decision owners come from [docs/tasks/DECISION_OWNERS.md](https://github.com/Kernol12/subathon-bot-ai/blob/b1c02b0d83e552e782b63189228a290a7524a2e3/docs/tasks/DECISION_OWNERS.md) and baseline pairs from the release epics. An owner is a work package accountable for test coverage. GitHub owns assignment and current task status.

Planned suite names describe test intent. Backlog IDs in parentheses identify existing baseline briefs. [docs/TEST_STRATEGY.md](https://github.com/Kernol12/subathon-bot-ai/blob/b1c02b0d83e552e782b63189228a290a7524a2e3/docs/TEST_STRATEGY.md) supplies exact current presets and CTest labels. Each citation names the supported slice, stage and environment. The live and platform gates remain open in this matrix.

The evidence pass selected 29 of 197 canonical proofs for specific scope matches, including leads identified in Tier B review. The other 168 proof records, other acceptance suites, PR and CI history outside cited records, and live artifacts were outside this evidence pass. An unassessed cell or absent citation leaves coverage unknown. Use the gate column for the remaining integrated checks and the canonical records for the limitations of each component result.

Evidence indexes use [tests/acceptance-map.json](https://github.com/Kernol12/subathon-bot-ai/blob/b1c02b0d83e552e782b63189228a290a7524a2e3/tests/acceptance-map.json), [docs/evidence/README.md](https://github.com/Kernol12/subathon-bot-ai/blob/b1c02b0d83e552e782b63189228a290a7524a2e3/docs/evidence/README.md) and the [progress/proof-policy.json](https://github.com/Kernol12/subathon-bot-ai/blob/b1c02b0d83e552e782b63189228a290a7524a2e3/progress/proof-policy.json) workflow. Authored needs a recorded revision/path. Reviewed needs an independent receipt bound to a revision. Observed red needs an attributable intended assertion failure. Implemented needs bounded source and passing acceptance evidence. Real SQLite and SDK results retain their component scope. Live/platform verified needs a recorded actual service or target run for the row.

MVP priority covers Linux server, Twitch API/chat, StreamElements, OBS browser overlay, Linux desktop management, English and Frankfurter. All other v0.45 gates remain in release scope.
