# Web module

React/TypeScript/Vite management/viewer and separate TypeScript overlay. No full scene editor, Node production service, direct DB access or service secrets. Preserve exact numeric JSON strings. Vitest and Playwright have separate responsibilities; OBS checks remain separate. Manifests are a frontend-foundation task, not silently selected here.
